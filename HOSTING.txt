# Хостинг: GitHub Pages

Это лучший бесплатный вариант для Velvet: HTTPS, статичные файлы, прямые ссылки на архивы. Свой сервер и домен не нужны.

Отсюда опубликовать сайт в ваш аккаунт нельзя — нет доступа к GitHub. Займёт около пяти минут.

1. Зарегистрируйтесь на https://github.com
2. Создайте публичный репозиторий `velvet-launcher`
3. Залейте в него содержимое этой папки: `index.html`, `version.json`, `icon.png`, `downloads`, `.nojekyll`
4. Settings → Pages → Branch `main` → папка `/` → Save
5. Сайт откроется по адресу `https://ВАШ-ЛОГИН.github.io/velvet-launcher/`
6. В `version.json` замените `https://example.com/` на этот адрес
7. В `update_url.txt` внутри сборок поставьте `https://ВАШ-ЛОГИН.github.io/velvet-launcher/version.json` и залейте архивы заново

После этого установленный лаунчер сам увидит новую версию, скачает нужный архив и обновится. Папку data он не трогает.
